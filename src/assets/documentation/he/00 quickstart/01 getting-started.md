# מדריך התחלה מהירה

## ברוכים הבאים!

ברוכים הבאים לאמולטור Assembly של x86! המדריך הזה יעזור לכם להכיר את האמולטור ולהריץ את התוכנית הראשונה שלכם.

זהו אמולטור ודיבאגר ל-Assembly של x86 שרץ בדפדפן, ומאפשר לכתוב, להריץ ולדבג קוד Assembly עם משוב חזותי. אפשר לראות את מצב המעבד, את תוכן הזיכרון ואת הפלט בקונסולה בזמן אמת, בזמן שהתוכנית רצה.

## היכרות עם הממשק

ממשק האמולטור מורכב מכמה רכיבים מרכזיים:

![Emulator Interface](assets/img/quick-start-interface.png)

### עורך הקוד (צד שמאל)
כאן כותבים את קוד ה-Assembly. העורך תומך ב:
- **מספרי שורות** להתמצאות קלה
- **הדגשת תחביר** לקריאות טובה יותר
- **נקודות עצירה** (לחיצה על ">" שליד מספרי השורות)
- **הדגשת השורה המתבצעת** בזמן דיבוג

### פלט הקונסולה (צד ימין, למעלה)
מציג פלט טקסט מהתוכנית כשמשתמשים בהוראה `INT 2` כדי להדפיס מחרוזות, או ב-`INT 1` כדי להדפיס מספרים.

### תצוגת המעבד (צד ימין, באמצע)
מציגה את המצב הנוכחי של כל האוגרים ודגלי המצב של המעבד, כולל:
- **אוגרים כלליים**: EAX, EBX, ECX, EDX ואחרים
- **אוגרים מיוחדים**: EIP (Instruction Pointer), EBP (Base Pointer), ESP (Stack Pointer)
- **דגלי מצב**: Zero Flag (ZF), Sign Flag (SF), Overflow Flag (OF) ועוד
- **מחוון קצב**: שליטה במהירות הביצוע

### תצוגת הזיכרון (צד ימין, למטה)
מציגה את תוכן הזיכרון בפורמטים שונים:
- **גודל מילה**: תצוגה של 1, 2 או 4 בתים
- **פורמט**: תצוגה כ-Decimal, Hex, ASCII או Binary

### כפתורי שליטה (למעלה)
- **Play** (▶): התחלה או המשך של הביצוע
- **Stop** (■): עצירת הביצוע ואיפוס
- **Pause** (⏸): השהיית הביצוע
- **Continue** (▶|): המשך מהשהיה
- **Step** (⏭): ביצוע הוראה אחת בכל פעם
- **Assemble**: הידור הקוד לפני ההרצה

## התוכנית הראשונה שלכם: Hello World

נתחיל עם תוכנית "Hello World" פשוטה. הדוגמה מדגימה תחביר Assembly בסיסי ואיך מציגים טקסט.

```nasm
section .data
hello:
    db 'Hello world!'
section .text
    MOV EAX, hello
    INT 2   ; print string EAX
```
<!-- console -memory -cpu --> 

> לחצו על כפתור `Try it` שלמעלה כדי לטעון את הדוגמה לאמולטור!

### הסבר הקוד

1. **`section .data`**: מגדיר את אזור הנתונים, שבו שומרים קבועים ומשתנים
2. **`hello:`**: תווית שמסמנת את מיקום המחרוזת שלנו
3. **`db 'Hello world!'`**: מגדיר מחרוזת בתים "Hello world!"
4. **`section .text`**: מגדיר את אזור הקוד, שבו נמצאות ההוראות
5. **`MOV EAX, hello`**: מעביר את הכתובת של המחרוזת hello לאוגר EAX
6. **`INT 2`**: פסיקת תוכנה שמדפיסה לקונסולה את המחרוזת שבכתובת EAX

## הרצת התוכנית שלב אחר שלב

כך מריצים את התוכנית הראשונה שלכם:

### שלב 1: טעינה או כתיבה של קוד
לחצו על "Try it" בדוגמה שלמעלה, או הקלידו את הקוד בעורך בעצמכם.

### שלב 2: הידור הקוד
לחצו על כפתור **Assemble** כדי להדר את קוד ה-Assembly. אם יש שגיאות תחביר, הן יוצגו.

### שלב 3: הרצת התוכנית
לחצו על כפתור **Play** (▶) כדי להריץ את התוכנית. הקוד ירוץ ותראו ש:
- "Hello world!" מופיע בחלונית **Console**
- ערכי האוגרים מתעדכנים בחלונית **CPU**
- תוכן הזיכרון מופיע בחלונית **Memory**

### שלב 4: הרצה צעד אחר צעד (רשות)
לצורך דיבוג אפשר:
1. ללחוץ קודם על **Assemble**
2. ללחוץ על **Step** (⏭) כדי לבצע הוראה אחת בכל פעם
3. לראות איך כל הוראה משנה את האוגרים ואת הזיכרון
4. לעקוב אחרי השורה הנוכחית שמודגשת בעורך

### שלב 5: הגדרת נקודות עצירה (רשות)
לחצו על הסימן ">" שליד מספרי השורות כדי להגדיר נקודות עצירה. כשתריצו את התוכנית, היא תיעצר בנקודות האלה ותוכלו לבדוק את המצב.

## הבנת ערכי האוגרים

בזמן שהתוכנית רצה, תראו ערכים משתנים בחלונית ה-CPU:

- **EIP** (Instruction Pointer): מראה איזו הוראה מתבצעת כרגע
- **EAX** (Accumulator): אוגר כללי, משמש לעיתים קרובות לערכי החזרה ולחישובים
- **EBP** (Base Pointer): מצביע על בסיס מסגרת המחסנית הנוכחית
- **ESP** (Stack Pointer): מצביע על ראש המחסנית (מתחיל ב-256)

אחרי הרצת דוגמת "Hello World" בדרך כלל תראו ש:
- EIP מתקדם עם ביצוע כל הוראה
- EAX מכיל את כתובת הזיכרון של המחרוזת "hello"
- שאר האוגרים נשארים בערכים ההתחלתיים שלהם

אזור ה-**Flags** מציג מידע על המצב:
- **ZF**: מקבל 1 כשתוצאת פעולה היא אפס
- **SF**: מקבל 1 כשהתוצאה שלילית
- **CF**: מקבל 1 כשיש נשא (carry) מהביט המשמעותי ביותר
