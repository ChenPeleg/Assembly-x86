# מספרים שליליים

במערכות מחשב מייצגים מספרים שליליים בדרך כלל בשיטה שנקראת המשלים ל-2 (two's complement). השיטה הזו מאפשרת לבצע פעולות חשבון ביעילות ומפשטת את התכנון של היחידה האריתמטית-לוגית (ALU) במעבד.

## ייצוג במשלים ל-2

בשיטת המשלים ל-2, הביט המשמעותי ביותר (MSB) משמש כביט הסימן. אם ה-MSB הוא 0 המספר חיובי, ואם ה-MSB הוא 1 המספר שלילי. כדי לקבל את הערך של מספר שלילי במשלים ל-2, הופכים את כל הביטים של המספר החיובי המקביל ואז מוסיפים 1 לביט הפחות משמעותי (LSB).

לדוגמה, במערכת של 8 ביטים:

| עשרוני | בינארי   | משלים ל-2 |
|---------|----------|------------------|
| 0       | 00000000 | 00000000         |
| 1       | 00000001 | 00000001         |
| -1      | 00000001 | 11111111         |
| 2       | 00000010 | 00000010         |
| -2      | 00000010 | 11111110         |
| 127     | 01111111 | 01111111         |
| -128    | 10000000 | 10000000         |

### המרה למשלים ל-2

כדי להפוך מספר חיובי למספר השלילי המקביל במשלים ל-2:
1. הופכים את כל הביטים (0 הופך ל-1, ו-1 הופך ל-0).
2. מוסיפים 1 למספר הבינארי שהתקבל.

דוגמה: המרה של `+5` ל-`-5` במערכת של 8 ביטים:
1. `+5` בבינארי: `00000101`
2. היפוך הביטים: `11111010`
3. הוספת 1: `11111010 + 1 = 11111011`

כלומר, `-5` במשלים ל-2 הוא `11111011`.

דוגמה:

```shell
section .text
mov [0], -5 
```

### פירוש עם סימן או בלי סימן

כשמפרשים מספר בינארי, חשוב לדעת אם הוא עם סימן (signed) או בלי סימן (unsigned). לדוגמה, המספר הבינארי `11111111` יכול לייצג `-1` במשלים ל-2, או 255 בשיטה ללא סימן. הפירוש תלוי בהקשר ובסוג הנתונים.
```shell
section .text
mov [0], -5 
mov [4], 4294967291
```
<!-- -cpu memory -console word:4 binary -->

<!-- warning -->
> בדוגמה הזו (במערכת של 32 ביטים) לערך `4294967291` יש אותו ייצוג בינארי כמו ל-`-5`. לכן צריך להיזהר כשמפרשים ערכים בינאריים, כי כל ערך בינארי אפשר לפרש כמספר שלם עם סימן או בלי סימן.

### פעולות חשבון

פעולות חשבון עם מספרים במשלים ל-2 פשוטות. אותם כללים של חיבור וחיסור בינאריים חלים, וביט הסימן מטופל אוטומטית.

דוגמה: חיבור של `-3` ו-2 במערכת של 8 ביטים:

1. `-3` בבינארי (משלים ל-2): `11111101`
2. 2 בבינארי: `00000010`
3. חיבור המספרים: `11111101 + 00000010 = 11111111`

התוצאה `11111111` היא `-1` במשלים ל-2.

```shell
section .text
mov [0], -3
add [0], 2
```
<!-- -cpu memory -console word:4 binary -->

### גלישה במשלים ל-2

גלישה יכולה להתרחש גם עם מספרים במשלים ל-2. היא קורית כשהתוצאה של פעולת חשבון חורגת מהטווח שאפשר לייצג במספר הביטים הנתון.

דוגמה: חיבור של 127 ו-1 במערכת של 8 ביטים:
1. 127 בבינארי: `01111111`
2. 1 בבינארי: `00000001`
3. חיבור המספרים: `01111111 + 00000001 = 10000000`

התוצאה `10000000` היא `-128` במשלים ל-2, וזה מצביע על גלישה.

### סיכום

המשלים ל-2 היא שיטה נפוצה לייצוג מספרים שליליים במערכות בינאריות. היא מפשטת פעולות חשבון ויעילה עבור חומרת המחשב. הבנה של המשלים ל-2 חיונית לעבודה בתכנות ברמה נמוכה ובארכיטקטורת מחשבים.
