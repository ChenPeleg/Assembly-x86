# האמולטור לעומת x86 אמיתי

| יכולת ב-x86 אמיתי                                   | באמולטור הזה                          |
|----------------------------------------------------|-------------------------------------------|
| `NOT` `NEG` `TEST` `SHL` `SHR` `SAR` `ROL` `ROR`   | לא נתמך                             |
| `LEA` `XCHG` `NOP` `MOVZX` `CBW` `CDQ`             | לא נתמך                             |
| `MUL` `DIV` `MOVSX` `JCXZ` `JECXZ`                 | מזוהות, אבל עדיין לא עובדות               |
| בינארי (`0b101`), סיומת `h`, `'A'` כמספר    | רק עשרוני ו-hex עם `0x`                 |
| `MOVS` `LODS` `STOS` `REP`                         | לא נתמך; `CLD`/`STD` רק משנות את DF |
| אוגרים של 64 ביטים, אוגרי מקטע, `EFLAGS`, AF  | לא נתמך                             |
| האוגרים של 16 ביטים `SP`, `BP`                        | לא זמינים                             |
| `PUSHAD` `POPAD` `PUSHF` `POPF`                    | לא נתמך                             |
| `global _start`, `.bss`, `equ`, `times`, `resb`    | לא נתמך                             |
| קריאות מערכת, מקלדת, קבצים                      | אין: רק `INT 1` ו-`INT 2`            |
| זיכרון                                             | מערך שטוח של בתים, בגודל שנבחר בממשק    |

<!-- info -->
> תוכניות שנכתבות כאן מלמדות את הרעיונות של x86, אבל צריך לשנות אותן כדי להדר אותן עם NASM במערכת אמיתית.
