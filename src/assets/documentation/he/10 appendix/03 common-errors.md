# שגיאות נפוצות

| הודעה / תסמין                | סיבה ותיקון                                                               |
|----------------------------------|-----------------------------------------------------------------------------|
| `Error at line N: ...`           | שגיאת תחביר או הוראה שלא נתמכת. בדקו את האיות ואת דף העזר. |
| Division by zero                 | המחלק הוא 0. בדקו אותו לפני `IDIV`.                                      |
| תוצאה שגויה של `IDIV`             | `EDX` לא אופס (0, או `-1` כש-`EAX` שלילי).                      |
| Memory access error              | הכתובת מחוץ לזיכרון. בדקו את המצביע או הגדילו את הזיכרון. |
| התוכנית לא מסתיימת               | תנאי הלולאה אף פעם לא נעשה שקרי, או ש-`ECX` היה 0 לפני `LOOP`.         |
| הביצוע ממשיך לתוך פרוצדורה            | חסר `HLT` לפני הקוד של הפרוצדורה.                                    |
| `RET` קופצת למקום מוזר   | `PUSH`/`POP` לא מאוזנים.                                                    |
| מודפסים תווים מיותרים          | אין `0` בסוף המחרוזת.                                          |
| מתבצעת הקפיצה הלא נכונה                 | נבחרה בטעות קפיצה עם סימן (`JL/JG`) במקום ללא סימן (`JB/JA`), או להפך.             |
| `Wrong size of operands`         | מספר רגיל הוא 32 ביטים. השתמשו ב-`MOV AL, byte 5`, `MOV AX, word 5`, `byte [x]`. |
