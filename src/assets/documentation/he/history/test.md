# אמולטור ומדריך Assembly x86

### ברוכים הבאים לאמולטור ולמדריך של Assembly x86!

האתר כולל מדריך ואמולטור לשפת Assembly של x86.
המדריך נועד להיות היכרות עדינה עם שפת Assembly, והאמולטור נועד לאפשר דרך פשוטה להריץ קוד Assembly ולדבג אותו.
הפרויקט מבוסס על:

- חלק ראשון
- חלק שני

אפשר להתחיל מהמדריך בפרק היסודות, להתחיל לשחק עם האמולטור, או לעבור לדוגמאות מתקדמות יותר.
בהתאם לניסיון שלכם עם Assembly, בחרו את המסלול שמתאים לכם.
תכנות מהנה!
