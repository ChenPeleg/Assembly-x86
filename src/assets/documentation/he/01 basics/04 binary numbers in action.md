
# מספרים בינאריים בפעולה

שיטת ספירה שמשתמשת בשני סמלים בלבד, בדרך כלל "0" ו-"1", נקראת **השיטה הבינארית**. היא נפוצה מאוד בטכנולוגיה דיגיטלית ומהווה את הבסיס של מערכות מחשוב. בשיטה הבינארית כל ספרה, שנקראת גם **ביט** (bit), מייצגת ערך של 0 או 1. הערך של מספר בינארי תלוי במיקום של הביטים שלו.


| ערך הביט | ערך המיקום כחזקה של 2 | מספר הביט |
|-----------|-------------------------------------|------------|
| 1         | 128                                 | 7          |
| 1         | 64                                  | 6          |
| 1         | 32                                  | 5          |
| 1         | 16                                  | 4          |
| 1         | 8                                   | 3          |
| 1         | 4                                   | 2          |
| 1         | 2                                   | 1          |
| 1         | 1                                   | 0          |



## קוד לדוגמה

הנה דוגמה לקוד Assembly ששומר מספר בינארי בזיכרון ואז קורא אותו:

```shell

section .text
MOV [0], 5
MOV [4], 30
MOV [8], 150
```
<!--  memory -console -cpu word:4 binary -->

הריצו את הקוד שלמעלה.
תראו שהמספרים 5, 30 ו-150 נשמרים בשלושת תאי הזיכרון הראשונים (כל תא זיכרון מייצג 4 בתים).

עכשיו תראו את הייצוג הבינארי של המספרים בתאי הזיכרון:

- `101`
- `11110`
- `10010110`

למה זה כך?

הייצוג הבינארי של המספרים הוא:

- `5 = 101`
  - `1*2^2 + 0*2^1 + 1*2^0 = 4 + 0 + 1 = 5`
- `30 = 11110`
  - `1*2^4 + 1*2^3 + 1*2^2 + 1*2^1 + 0*2^0 = 16 + 8 + 4 + 2 + 0 = 30`
- `150 = 10010110`
  - `1*2^7 + 0*2^6 + 0*2^5 + 1*2^4 + 0*2^3 + 1*2^2 + 1*2^1 + 0*2^0 = 128 + 0 + 0 + 16 + 0 + 4 + 2 + 0 = 150`
