# האוגרים

אמנם אפשר לגשת לזיכרון בעזרת ההוראה `MOV`, אבל אפשר גם להשתמש באוגרים (registers) כדי לשמור נתונים ולבצע פעולות. אוגרים הם יחידות אחסון קטנות בתוך המעבד, שמשמשות לשמירה זמנית של נתונים. אוגרים מהירים בהרבה מהזיכרון, ולכן שימוש בהם יכול לשפר את ביצועי התוכנית.
בנוסף, אוגרים משמשים לשמירת תוצאות של פעולות חשבון ולוגיקה, וכן לשמירת כתובות זיכרון ונתונים אחרים. בארכיטקטורת x86 יש קבוצה של אוגרים כלליים שאפשר להשתמש בהם למטרות שונות: שמירת נתונים, ביצוע פעולות חשבון ולוגיקה ושליטה בזרימת התוכנית.

## מהם אוגרים?

אוגרים הם יחידות אחסון קטנות בתוך המעבד, שמשמשות לשמירה זמנית של נתונים. הם מהירים בהרבה מהזיכרון, ולכן שימוש בהם יכול לשפר את ביצועי התוכנית. אוגרים משמשים גם לשמירת תוצאות של פעולות חשבון ולוגיקה, כתובות זיכרון ונתונים אחרים, וכן לשליטה בזרימת התוכנית.

### אוגרים כלליים

האוגרים הכלליים בארכיטקטורת x86 הם:

- **EAX**: אוגר צובר (Accumulator)
- **EBX**: אוגר בסיס (Base)
- **ECX**: אוגר מונה (Counter)
- **EDX**: אוגר נתונים (Data)
- **ESI**: אינדקס מקור (Source index)
- **EDI**: אינדקס יעד (Destination index)
- **EBP**: מצביע בסיס (Base pointer)
- **ESP**: מצביע מחסנית (Stack pointer)

אפשר להשתמש באוגרים האלה כדי לשמור נתונים, לבצע פעולות חשבון ולוגיקה ולשלוט בזרימת התוכנית. לכל אוגר יש תפקיד מקובל, והוא משמש בהקשרים שונים.
לדוגמה, האוגר `EAX` משמש בדרך כלל כצובר שבו נשמרות תוצאות של פעולות חשבון, והאוגר `EBX` משמש לעיתים קרובות כאוגר בסיס לשמירת כתובות זיכרון.

### דוגמה 1: שימוש באוגר EAX

```shell
section .text
    MOV EAX, 1  ; Move the value 1 into the EAX register
    ADD EAX, 1  ; Add 1 to the value in the EAX register
    ADD EAX, 2  ; Add 2 to the value in the EAX register
    INT 1       ; Call the interrupt 1 (print the value in EAX)
```

מלבד האוגרים הכלליים, בארכיטקטורת x86 יש גם אוגרי מקטע (segment registers), אוגרי בקרה (control registers) ואוגרי דיבוג (debug registers). הם משמשים למטרות מיוחדות, כמו ניהול מקטעי זיכרון, שליטה בפעולת המעבד ודיבוג תוכניות.

### אוגרי בקרה

האוגר **EIP** (Extended Instruction Pointer) בארכיטקטורת x86 הוא אוגר בקרה שמחזיק את הכתובת של ההוראה הבאה לביצוע. המעבד מעדכן אותו אוטומטית בזמן ביצוע ההוראות. האוגר EIP חיוני לזרימת התוכנית, כי הוא קובע באיזה סדר ההוראות נשלפות ומתבצעות.

### דוגמה 2: צפייה באוגר EIP

```shell
section .text
    MOV EAX, 0
    MOV EAX, 0
    MOV EAX, 0
    MOV EAX, 0
    MOV EAX, 0
    MOV EAX, 0
```
<!-- -console -memory cpu -->
שימו לב שהאוגר `EIP` לא מופיע בקוד, אבל אפשר לראות אותו בתצוגת האוגרים של האמולטור.
בכל פעם שהוראה מתבצעת, האוגר `EIP` מתעדכן כך שיצביע על ההוראה הבאה לביצוע.

### דוגמה 3: שימוש באוגר ECX

```shell
section .text
    MOV ECX, 5  ; Move the value 5 into the ECX register
loop_1:
    MOV EAX, ECX  ; Move the value in ECX into EAX
    INT 1         ; Call the interrupt 1 (print the value in EAX) 
    LOOP loop_1      ; Jump to the loop label if ECX is not zero
```
<!-- -memory cpu  console -->

כפי שאפשר לראות, בדוגמה הזו האוגר `ECX` משמש כמונה. ההוראה `LOOP` מקטינה את `ECX` באחד וקופצת לתווית שצוינה אם `ECX` אינו אפס. כך אפשר לחזור על קטע קוד מספר מסוים של פעמים.
האוגר `ECX` משמש בדרך כלל כמונה בלולאות ובפעולות חוזרות אחרות.
