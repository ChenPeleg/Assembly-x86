# זיכרון

זיכרון הוא מושג יסוד במדעי המחשב ובתכנות. הזיכרון משמש לשמירת נתונים והוראות שהמחשב משתמש בהם כדי לבצע משימות שונות. הזיכרון מחולק לשני סוגים עיקריים: זיכרון מחסנית (stack) וזיכרון ערימה (heap).
זיכרון המחסנית משמש לשמירת משתנים מקומיים, פרמטרים של פונקציות, כתובות חזרה ונתונים אחרים שהתוכנית משתמשת בהם. זיכרון הערימה משמש לזיכרון שמוקצה באופן דינמי, כמו אובייקטים, מערכים ומבני נתונים אחרים.
נרחיב על המחסנית והערימה בחלקים הבאים.

<!-- warning -->
> בעמוד הזה נשתמש בדוגמאות פשוטות מאוד כדי להדגים איך המחסנית והערימה עובדות. בתוכניות אמיתיות
> המבנה שונה ומורכב יותר.

# הערימה (Heap)

הערימה היא אזור בזיכרון שמשמש לשמירת זיכרון שמוקצה באופן דינמי: אובייקטים, מערכים ומבני נתונים אחרים שנוצרים בזמן ריצה. מערכת ההפעלה מנהלת את הערימה, והתוכנית יכולה לבקש ממנה זיכרון באמצעות הפונקציות `malloc` ו-`free`. הערימה היא אזור זיכרון גדול, שנמצא בדרך כלל בתחתית מרחב הזיכרון וגדל כלפי מעלה.

במדריך ובאמולטור הזה, הערימה מיוצגת כאזור בזיכרון שמשמש לשמירת נתונים שמוקצים באופן דינמי, והיא החלק הראשון (התחתון) של הזיכרון. שימו לב ש**זה לא המצב בתוכניות אמיתיות**.

# המחסנית (Stack)

המחסנית היא אזור בזיכרון שמשמש לשמירה זמנית של נתונים. המחסנית היא מבנה נתונים מסוג LIFO (last-in, first-out, נכנס אחרון יוצא ראשון), כלומר הפריט האחרון שנוסף למחסנית הוא הראשון שיוצא ממנה. המחסנית משמשת לשמירת משתנים מקומיים, פרמטרים של פונקציות, כתובות חזרה ונתונים אחרים.
כשמערכת ההפעלה מפעילה תוכנית, היא מקצה לה מחסנית. המחסנית נמצאת בדרך כלל בראש מרחב הזיכרון וגדלה כלפי מטה. האוגר מצביע המחסנית (ESP) מצביע על ראש המחסנית, והמחסנית גדלה כלפי מטה ככל שדוחפים אליה פריטים.

## איך המחסנית עובדת

כדי להדגים איך המחסנית עובדת, נסתכל על הדוגמה הבאה:

```shell

section .text
    mov [0], 72 ; Store the value 72 (char H) at memory address 0
    mov [4] , 101 ; Store the value 101 (char e) at memory address 4
    mov [8] ,97 ; Store the value 87 (char a) at memory address 8
    mov [12] , 112 ; Store the value 108 (char p) at memory address 12
    push 107 ; Push the value 107 (char k) onto the stack
    push 99 ; Push the value 99 (char c) onto the stack
    push 97 ; Push the value 97 (char a) onto the stack
    push 116 ; Push the value 116 (char t) onto the stack
    push 83 ; Push the value 83 (char s) onto the stack
```

<!--  memory -console -cpu word:4 ascii -->


זו דוגמה פשוטה מאוד שמדגימה איך המחסנית עובדת. בדוגמה אנחנו שומרים בזיכרון את התווים 'H', 'e', 'a', 'p', ואז דוחפים למחסנית את התווים 'k', 'c', 'a', 't' ו-'s'. המחסנית גדלה כלפי מטה בכל פעם שדוחפים אליה פריט, ומצביע המחסנית (ESP) מתעדכן כך שיצביע על ראש המחסנית.

## דחיפה ושליפה של פריטים מהמחסנית

```shell

section .text

    push 99 ; Push the value 99 (char c) onto the stack
    pop EAX; pops the value from the stack
    push 98 ; Push the value 98 (char b) onto the stack
    pop EAX; pops the value from the stack
    push 99 ; Push the value 99 (char c) onto the stack

```

<!--  memory -console -cpu word:4 ascii -->

כשדוחפים (push) פריט למחסנית, מצביע המחסנית קטן כך שיצביע על המקום הפנוי הבא במחסנית. כששולפים (pop) פריט מהמחסנית, מצביע המחסנית גדל כך שיצביע על הפריט הבא במחסנית.
