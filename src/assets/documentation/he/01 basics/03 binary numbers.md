## השיטה הבינארית

כדי להבין לעומק את שפת Assembly, חשוב להכיר את השיטה הבינארית. השיטה הבינארית היא הבסיס של כל המערכות הדיגיטליות, כולל מחשבים. בחלק הזה נכיר את השיטה הבינארית, ספרות בינאריות, ערך המקום, המרה מבינארי לעשרוני ושימושים של השיטה הבינארית.

שיטת ספירה שמשתמשת בשני סמלים בלבד, בדרך כלל "0" ו-"1", נקראת **השיטה הבינארית**. היא נפוצה מאוד בטכנולוגיה דיגיטלית ומהווה את הבסיס של מערכות מחשוב. בשיטה הבינארית כל ספרה, שנקראת גם **ביט** (bit), מייצגת ערך של 0 או 1. הערך של מספר בינארי תלוי במיקום של הביטים שלו.

### ספרות בינאריות

בשיטה הבינארית כל ספרה נקראת **ספרה בינארית** (binary digit) או **ביט**. לביט יש אחד משני ערכים אפשריים: 0 או 1. הערכים האלה מתאימים להיעדר או לנוכחות של אות חשמלי במערכות אלקטרוניות.

### ערך המקום

השיטה הבינארית בנויה על **ערך המקום**, בדומה לשיטה העשרונית. אבל במקום חזקות של 10, השיטה הבינארית משתמשת בחזקות של 2. המיקום של כל ביט מייצג חזקה של 2, החל מהביט הימני ביותר:\
\
`... 2^4  2^3  2^2  2^1  2^0`\
\
לדוגמה, במספר בינארי של 4 ביטים, הביט הימני ביותר מייצג `2^0` (1), הביט הבא מייצג `2^1` (2), הביט שאחריו מייצג `2^2` (4), וכן הלאה.

### המרה מבינארי לעשרוני

כדי להמיר מספר בינארי לעשרוני, מכפילים כל ביט בערך המקום שלו ומחברים את התוצאות. לדוגמה, את המספר הבינארי 1010 ממירים לעשרוני כך:\
\
`(1 * 2^3) + (0 * 2^2) + (1 * 2^1) + (0 * 2^0) = 8 + 0 + 2 + 0 = 10`\
\
כלומר, המספר הבינארי 1010 שווה למספר העשרוני 10.\

### שימושים

השיטה הבינארית היא יסוד במערכות מחשוב דיגיטליות, שבהן מידע נשמר ומעובד באמצעות ספרות בינאריות. היא מאפשרת לייצג נתונים ביעילות, ומאפשרת לתכנן מעגלים אלקטרוניים שמעבדים מידע בינארי. השיטה הבינארית משמשת רבות בתכנות, במערכות תקשורת ובתחומים אחרים של טכנולוגיית מידע.
