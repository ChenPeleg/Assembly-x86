# Glossary

- **Address**: the number of a byte in memory.
- **Carry**: a bit that does not fit in an unsigned result (CF).
- **Flag**: one bit describing the last result (ZF, SF, CF, OF, PF, DF).
- **Frame**: the stack area of one procedure, pointed to by `EBP`.
- **Immediate**: a number written in the instruction, such as `5` in `MOV EAX, 5`.
- **Instruction**: one command to the CPU.
- **Label**: a name for an address.
- **Little endian**: the lowest byte is stored first.
- **Operand**: a value an instruction works on.
- **Register**: a small, fast storage place inside the CPU.
- **Stack**: last-in first-out memory at the top of memory, used by `PUSH`, `POP`, `CALL`, `RET`.
- **Word**: 16 bits. **Double word**: 32 bits.
